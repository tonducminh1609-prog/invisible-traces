Không Gian 01

1. KHU VỰC TIẾP BIẾN (Aesthetics)

Nơi tôn vinh vẻ đẹp nguyên bản của thủ công truyền thống: đường cong của bình gốm chưa nung, tiếng thoi đưa nhịp nhàng tại làng lụa, và màu óng ả của những thanh đồng mới đúc.

Trải nghiệm: Ánh sáng ấm 3000K, hiện vật lơ lửng.
Không Gian 02

2. KHU VỰC VI VẾT (Residues)

Cú rơi về hiện thực: Ống kính macro phóng to tinh thể kim loại nặng, mẫu nước sông Nhuệ sẫm màu hóa chất dệt, và tấm phim X-quang chụp lá phổi của người thợ đúc đồng.

Trải nghiệm: Ánh sáng phòng tối, kính hiển vi tương tác.
Không Gian 03

3. KHU VỰC HỒI SINH (Regeneration)

Đối thoại tương lai: Bàn tròn trưng bày các sáng kiến tuần hoàn sinh thái – men gốm sinh học không chì, gạch nung từ xỉ đồng tái chế, và các bãi lọc thực vật xử lý nước thải.

Cách Đưa Website Này Lên GitHub Pages Miễn Phí

Chỉ mất 2 phút để trang web Invisible Traces của bạn chạy trực tiếp trên Internet

  1. Bước 1: Tạo Repository trên GitHub Vào github.com/new, tạo repository mới đặt tên là invisible-traces (chọn chế độ Public).
  2. Bước 2: Tải file lên Lưu toàn bộ nội dung file này với tên chính xác là index.html. Sau đó tải file này lên root của repository vừa tạo.
  3. Bước 3: Kích hoạt GitHub Pages Trong repo, chọn Settings > mục Pages (ở thanh bên trái) > tại Branch, chọn main và folder / (root) > Bấm Save.
  4. Bước 4: Hoàn tất Sau 1 phút, GitHub sẽ cung cấp link công khai dạng:
    https://<tên-tài-khoản>.github.io/invisible-traces/
